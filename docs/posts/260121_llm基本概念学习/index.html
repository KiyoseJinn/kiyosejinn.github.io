内容（Content）

LLM是什么

基于Transformer架构的大神经网络

Transformer架构的机制：

1. Self Attention：每个token观察全体token

  • 对于每个token，计算它对所有token的相关权重，再将所有token信息按权重相加，得到新表示。attention输出的是value的加权和。
  • 从输入序列X中生成Q, K, V 向量:
    • Query：当前token想要寻找什么信息
    • Key：当前token能提供什么特征供检索
    • Value：当前token包含的具体语义内容

2. Scaled Dot-Product Attention: 怎么计算token之间的相关性aij

  • 得到 Q, K, V 向量
  • 点积计算相似度
    • Scaling：点积结果除以根号下向量维度dk来稳定尺度，避免点积过大,softmax过尖，导致梯度退化（稀疏/不稳定/学不动）
  • softmax映射成概率权重
  • 对Value加权求和

3. Multi-head Attention：上述过程并行运行多次

  • 允许不同维度同时理解语言（将同一输入通过不同的线性投影矩阵映射到多个子空间），学习不同关系模式
  • 最后整合所有头的输出：
    • Concatenation：把所有attention head的输出向量拼成一个长向量
    • Output Projection：长向量乘以一个在训练过程中学习的权重矩阵Wo
      • Wo通过反向传播，从loss的梯度（例如 next-token loss）中学习/更新参数
      • Wo学习了哪些head输出对降低loss有帮助，如何把拼接后信息以最有用的形式恢复维度

4. Residual Connection： 把层的输入直接加到该层输出上

  • 缓解反向传播时梯度消失
  • 加层不用每一层重学完整映射构建新表示，只学增量修正
    • MHA的增量：跨token的信息
    • FFN的增量：逐token提取的新特征组合
  • 深层网络不会因层数增加被迫误差上升（可模拟浅层解）
  • 残差链接要求输入与输出维度一致，迫使结构设计上固定每层的表示维度，该结构便于层数堆叠

5. Layer Normalization：对token的特征维度 embedding dim 做归一化

  • 校准到稳定数值区间，控制层数叠加导致的尺度漂移
    • 均值拉到0，方差拉到1，再用参数调回合适尺度
    • 𝛾 ：可学习缩放，学“需要多大幅度”
    • β：可学习平移，学“需要什么基线偏置”
  • 通过控制x尺度防止注意力计算（2）中的softmax梯度消失
  • 通过控制x尺度减少深层网络链式法则连乘导致的梯度消失/爆炸概率

6. Feed-Forward Network：对每个token的向量进行非线性变化，提取更复杂的语义特征

  • 由两层Multi-layer Perceptron构成，FC layer+非线性激活
  • 产生一个修正向量，作为残差与输入相加

7. Positional Encoding：为token添加顺序信息，识别绝对和相对位置

  • 绝对位置编码
  • 相对位置编码
  • 旋转位置编码 RoPE

Transfomer的一次前向传播流程

输入阶段：X

  • tokenization + embedding + positional encoding

进入Transformer Block：

  • LayerNorm ： U = LN(X)
  • MHA: 上述提到（1）（2）（3）
  • 多个attention head
  • 每个head内部：
    • 线性投影得Q, K, V
    • 计算token对所有token的相关性权重（含scaling）
    • softmax映射成概率权重，计算V的加权和
    • multihead输出 -> concat -> output projection
  • Residual: X <- X + MHA(U) 加上注意力增量
  • LayerNorm: U’= LN(X)
  • FFN：对特征维度非线性加工
  • Residual： X <- X + FFN(U')

到最后一层：语言模型头做预测
