今天发生了什么（What）

1.代码与实验管理

今天订阅了 Claude Pro，把四个实验的具体情况告诉它，让它在现有代码基础上整合出一套能实现这四个实验的方案并用代码实现。它完成得不错——在原有代码基础上新增了分阶段的实验代码，整体还挺简洁。之后进一步用它整理了这四个实验的 Pipeline，把各自的存档路径确认清楚并分配好，最后把更新推送到了 GitHub，但还没有在实验室电脑上实际跑起来。

2.研究规划

用 Notebook LM 重新梳理了一下自己的研究方向，确认了理论基础框架。这对之后写作会有帮助。不过具体文献还没有细读，目前整体感觉还好，没有太大问题。

3.关于 OpenClaw / AI Agent 工具的思考

最近看到有关 OpenClaw 的讨论，有点担心自己落后于时代，所以专门去了解了一下。结论是：目前配置和使用它的动机不强，原因有几点：

  • OpenClaw 最大的价值在于自动化重复性工作，但自己目前还没有正式工作，繁琐事务不多，痛点不明显
  • 朋友圈有人在推"做科研用 OpenClaw"，但感觉它本质上只是几个 Agent 的集合
  • 它的几个主要功能——推送领域新论文、总结研究空白和方向——这些用现有工具其实完全可以做到
  • 安全隐患：给它账号权限去修改东西风险较大
  • Token 消耗量非常大，成本问题也需要考虑

4.对 OpenClaw 热潮的观察

最近感觉 OpenClaw 这个话题在国内炒得有点过热。关注的 AI 相关自媒体，每天更新3到5篇相关文章，频率比之前高出很多，在国内似乎也作为技术热点发酵起来了。但个人感觉这波热度存在一定泡沫成分
